# Lukulu Academy Consolidated

Unified development workspace for Lukulu Academy.

## Product areas
- **Public Academy website**: use the approved white-interface "Lukulu Academy Consolidated" design as the visual baseline; public course information, pricing, enrolment.
- **Student portal**: preserve the green Lukulu learning-hub direction; authentication, learning materials, daily quizzes and progress.
- **DAW simulator**: educational FL Studio-inspired workflow; practical lessons and exercises.
- **Demo mode**: full-access preview with clearly marked sample data, without bypassing production authentication or payments.

## Development safeguards
- Do not modify or deploy the existing projects while consolidating.
- Audit assets, licences, branding and dependencies before importing.
- Do not commit secrets, API keys, student records or payment credentials.
- Confirm the final pricing before publication.
- Keep production enrolment and payment flows separate from demo mode.
